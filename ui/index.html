Which integration method should I choose?

Is GUI automation a good option if the cash register is connected?

Connect to the inventory software directly through its API or a verified file export whenever possible. GUI automation is a fallback and is not implemented in this app.

Consider it only when

A supported export cannot be obtained through an API or command-line tool, and automation would not interrupt the cashier.

Prefer another method when

The device stores sales rather than full stock, the PC is often locked, or frequent interface changes make clicks unreliable.

Add connection

CSV import format

Use exact export headers. Required: source_code, quantity, warehouse, observed_at (timestamp with timezone). Optional: name, price and currency together; ean. Whole units only. Match quantity meaning and units to the destination; no reservation or unit conversion. Stock-only imports can sync but cannot create stock.csv without verified catalogue data.

Credentials stay in OS encrypted storage and are never returned to this page. A read test does not verify write access.

Connection groups

Choose authority, permissions, mappings and polling interval.

Configure group

Select at least two members. Master must have source role. Each mapping line is local ID = shared ID. Every source item and warehouse must be explicitly mapped. Two-way requires all members to support atomic writes; WooCommerce and generic POS are excluded.

Inventory synchronization

Sync Now can update destinations with read/write permission. Review mappings and test with sandbox stores first. Schedules run only while this application remains open.

Failed atomic operations retry with backoff (up to five attempts). Changed destinations and uncertain non-atomic writes are held. Held jobs require reconciliation; automatic overwrite is never used to resolve them.

Inspect products & warehouses

Read the connection's inventory to discover exact IDs. No automatic SKU or display-name matching.

Up to 1,000 observations shown. Use explicit per-member product and warehouse maps in Connection Groups.

Sync history

Conflict history

Historical conflict records are retained. Correct quantities at the source after review; only agreement establishes a new two-way baseline. Outstanding jobs must be reconciled separately.

Persistent jobs

Connector support & sync capacity

Connection count and vendor compatibility are separate. Each configured connection uses one of the implemented drivers below; setup-required methods cannot synchronize.

Schedules spread startup across the polling interval and wait for each run to finish. Increase intervals when provider limits or inventory size make runs slow. Queue overflow is reported and deferred to the next scheduled run.

Local workspace

Default output: stock.csv + manifest.json

Local exports require source code, product name, price, currency and quantity. Multi-warehouse exports require an explicit aggregation policy and are held if product codes repeat.

No telemetry or cloud account is required for local exports. Windows credentials use Electron safeStorage / DPAPI under your Windows account.
