Configure group

Select at least two members. Master must have source role. Each mapping line is local ID = shared ID. Every source item and warehouse must be explicitly mapped. Two-way requires all members to support atomic writes; WooCommerce and generic POS are excluded.

Inventory synchronization

Sync Now can update destinations with read/write permission. Review mappings and test with sandbox stores first. Schedules run only while this application remains open.

Failed atomic operations retry with backoff (up to five attempts). Changed destinations and uncertain non-atomic writes are held. Held jobs require reconciliation; automatic overwrite is never used to resolve them.
